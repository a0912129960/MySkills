# Callouts

```markdown
> [!note]
> Basic callout.

> [!warning] Custom title
> Important detail.

> [!faq]- Collapsed initially
> Foldable content.
```

`-` starts collapsed and `+` starts expanded. Common types include `note`,
`tip`, `warning`, `info`, `example`, `quote`, `bug`, `danger`, `success`,
`failure`, `question`, `abstract`, and `todo`.
