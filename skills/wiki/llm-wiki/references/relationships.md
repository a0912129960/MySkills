# Typed relationships

Use ordinary links in prose and typed relationships when the relation changes graph meaning.
Common types include:

- `supports`
- `contradicts`
- `extends`
- `implements`
- `depends-on`
- `derived-from`
- `supersedes`
- `related`

Choose the narrowest relationship supported by evidence. Do not turn co-occurrence into a
causal claim. Maintain reciprocal navigation where the workflow contract requires it, while
avoiding duplicate links that add no retrieval value.
