# Retrieval

Start with the vault index and frontmatter. Use the MySkills-managed CLI for deterministic
ranking and graph traversal. QMD may add semantic candidates when available, but its absence
must not prevent the primary Wiki workflow.

Escalate reads in this order:

1. titles, aliases, tags, categories, summaries;
2. likely page bodies;
3. typed neighbors and source provenance;
4. broader graph search only when the evidence remains insufficient.

Answers distinguish quoted or directly supported facts, synthesis, uncertainty, stale
material, contradictions, and missing knowledge. Cite vault-relative pages.
